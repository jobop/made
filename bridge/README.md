# bridge

电脑侧桥接器。设备 API 在 `8788`，工作台在 `127.0.0.1:8787`。

内部仍是桥接器自己的运行结构：

- `src/`：服务、设备接口与内置 agent
- `public/`：工作台
- `plugins/`：已安装、由桥接器加载的插件
- `themes/`：已安装主题
- `examples/`：示例
- `tools/`：开发工具
- `test/`：测试

插件市场和专家市场只负责发包，不放在这里。包安装进本目录之后，桥接器才会加载。配置文件是本目录的 `config.local.json`。

在仓库根目录执行 `npm start` 或 `npm test` 会转到这里。
